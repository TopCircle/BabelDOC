    视觉版式达标验收定义（v1）

    2026-08-13: Still valid as acceptance criteria, not a work queue.
    Scheduling: oa-dual-quality-wave-0.6.4.69.md. Wave page gates (切除子宫 / p68 EN / p91 overlap / …) sit on top of V1–V5.

    背景：0.6.4.57–66 在"复刻 EN 绕图锥形"上迭代 6 版未收敛——CJK 等宽方块结构上无法复刻 EN 词宽参差（P2"左缘±2pt"不可达）。本定义改以英文原版为版式基准、但按"读者能否看出是同一本书的版式"验收。

    0. 原则

    • 锚点对位 + 间距合理 + 绕排不糊 + 内容不重不漏 + 结构不塌 = 达标；
    • 不要求逐像素复刻 EN（特别是绕图左缘）；
    • 每条可自动化断言（进 tests/repro digest），替代"目视截图"。

    1. 验收维度

    V1 锚点对位（硬性）

    • 章标题顶 / 节标题顶 / 正文首行顶 vs 原版：|Δy| ≤ 4pt
    • 已证明可达：p82 三段正文首行 147/207/252 与原版完全对齐
    • 例外：P1 gap 契约允许的间距调整不视为漂移

    V2 间距契约（硬性，P1 回归）

    • 大标题→正文：|zh_ink_gap − en_ink_gap| ≤ ε（ε=2pt）
    • p19 状态（0.6.4.66 修复后）→ PASS：zh_ink_gap 20.07pt vs en_ink_gap（gap_contract）19.54pt，|Δ|=0.53 ≤ 2（typsetting.json 渲染 ink 测量）。根因：gap_contract 提取被首行 drop-cap 干扰（11.21pt）；修复后按首行正文测量并触发首遍预留（shift −8.33pt）。

    V3 绕排可读（替代"左缘±2pt"）

    • 右缘 = design 右缘 ±0.5pt（0.6.4.66 已达 ✓）
    • 无单字/双字孤行（新增 CJK 孤行保护；p19 现仍有"的"单字行）
    • 字号 ≥ min_scale × 原字号（当前 10.8pt ✓）
    • 不压照片主体（可选 IoU 断言）

    V4 内容完整性（硬性，阻断）

    • 中文栏无同句连续重复 ≥2（p82"×4 重复墙"= 阻断）
    • 无半截句 / 悬空标点
    • 段落行数 ≥ 原版语义下限（中文紧凑，允许 3/5）

    V5 结构还原

    • callout/侧栏：中文与英文一一对应（不重复、不合并丢句）
    • 列表符号/编号保留
    • 页眉/页脚 skip 生效：页眉/页脚 chrome（如 "Learn The Trigasm"、页脚 URL/页码）整体保 EN；章节名 "Chapter N + 标题" 是标题，必须翻译为通顺中文（如 p82 应为 "第九章 直接卷曲"；"Chapter9直接卷曲" 半中半英 = FAIL）

    2. 分级

    级 触发
    P0 阻断 V4 重复/截断、V2 间距塌、V5 结构崩、页脚带中文侵入
    P1 V1 锚点 >4pt、V3 孤行、字号 < min_scale
    P2 绕图左缘形状差异（不再作为验收，仅记录）

    3. 修复清单（对齐 p19/p82 现状）

    1. [P0·间距] p19 标题→正文间距塌（≈0 vs 20pt） → 定位 layout_intent.json：gap_contract 是否提取到"成为行动派→正文"对；首遍预留是否被 drop-cap 行序修复后的正文行位置干扰；post-pass 审计为何没补。
    2. [P0·内容] p82 callout 同句 ×4 重复 → 定位 ParagraphFinder/ILTranslator 段落组装（同一 span 多次进 MT）；加"同段输出重复检测"门（≥2 即报警/回退）。
    3. [P1·绕排] CJK 孤行保护（单字/双字行尾） → wrap 消费端 kinsoku/孤行；"的"/"男人，让"类孤行禁止。
    4. [P1·MT] 章节名 "Chapter N + 标题" 必须完整翻译（p82 应为 "第九章 直接卷曲"） → 章节名是标题，不得被 header skip 保 EN（p19/p82 一致翻译）；MT 若残留 "Chapter N" 英文标记（p82"Chapter9直接卷曲"），由输出侧 fix_untranslated_chapter_markers 归一为 第N章。
    5. [P2·验收基建] 上述 V1–V5 自动化断言进 tests/repro/digest.py：
    6. 锚点 |Δy|≤4、间距 |Δ|≤2、右缘 ±0.5、无重复行、无孤行、无越栏、字号 ≥ min_scale
    7. p19/p82 作为固定验收页（含 golden）。

    4. 与既有文档关系

    • 取代 plan §7 规则 4"左缘步进 ±2pt"（删除，改为 V3 右缘+无孤行）；
    • 保留 V2（= coding-plan §3.1 相对 EN gap，P1 已有）；
    • V4/V5 是"内容轨"验收，Layout-First 排版轨必须与内容轨（段落组装/skip）共同达标才可交付。
